## Scope and upstream review

| Package | Before → after | Impact and decision |
| --- | --- | --- |
| certifi | 2026.7.22 → 2026.10.23 | Accept. Development dependency through HTTPX/HTTPcore, not a published snekql runtime requirement. Removes compromised emSign trust roots; affects TLS trust for development HTTP clients. |
| opentelemetry-api | 1.45.0 → 1.45.1 | Accept. Published optional telemetry extra. Fixes quadratic inbound tracestate parsing and rejects combined headers over 8192 characters. Raise the extra's minimum to 1.45.1 so downstream resolution cannot select an affected API. |
